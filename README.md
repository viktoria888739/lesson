# Мастерская памяти

Консольная викторина на C++17: 10 вопросов о копировании, перемещении и операторах. Фрагменты `RawArray` и `IntArray` только показываются как текст и в программе не выполняются.

## Сборка

```bash
clang++ -std=c++17 -Wall -Wextra -pedantic main.cpp -o quiz
```

На этой машине сборка проверялась компилятором MSVC:

```bat
cl /std:c++17 /W4 /permissive- /EHsc /utf-8 main.cpp /Fe:quiz.exe
```

Флаг `/utf-8` нужен, чтобы русский текст в исходнике читался как UTF-8.

## Запуск

```bash
./quiz
```

В консоли Windows перед запуском переключите кодировку, иначе буквы отобразятся неверно:

```bat
chcp 65001
quiz.exe
```

## Ввод

Главное меню:

- `1` — новая игра с вопроса 1 и нулевым счётом
- `2` — правила и оценки, затем возврат в меню
- `0` — выход

В вопросе принимается одна цифра `1`, `2` или `3`. Пробелы и табуляции вокруг цифры допустимы: строка ` 2 ` — это ответ 2. Пустая строка, `abc`, `1abc`, `1.0`, `+1`, `1 2` и числа вне диапазона отклоняются. Тот же вопрос задаётся снова, счёт не меняется.

После пояснения пустая строка или строка только из пробелов переходит дальше. Любой другой текст снова просит нажать Enter.

Верный ответ даёт 10 баллов, неверный — 0. Максимум 100. Повторно ответить на тот же вопрос нельзя. Между запусками программы результат не сохраняется.

Конец ввода (EOF) завершает программу. Если игра не доиграна до результата, она помечается как прерванная, и итоговая оценка не выставляется.
